# 样例资料说明

`site.seed.json` 是保留业务结构的作品集样例，不是实时招生数据库。

- 保留 261 所院校及已有的专业、QS 排序字段、匹配规则、申请流程与签证清单。87 所院校处于前台显示状态。
- 资料来自本项目此前整理的院校介绍、招生材料和排名记录；本次重构没有重新核验各项事实，也没有调整原有排名。
- 学校名称、招生条件、排名年度与签证要求可能变化。实际申请请查当期院校和受理机构发布的信息，不能以本项目作为唯一依据。
- 联系入口替换为 `demo` 与 example.org 演示地址。咨询线索为空，没有用户账号或密码；原始 Excel/PDF 和本机资料不随样例发布，公开来源链接保留。
- 保留资料用于展示信息组织、导入和管理能力，不代表对学校、QS、招生文件或其他第三方内容取得了再许可。发布前仍需审查相关内容的使用范围。

默认运行时首次读取样例；只有保存内容、注册或提交表单后，才在 `.local/` 下创建独立的可写文件。源码中的样例不会被后台编辑覆盖。
