## 回归测试中修复的问题

1. 旧 public 目录中的入口文件会覆盖新的应用入口，导致空构建；改为仅从源码构建。
2. 公开 API 会暴露咨询线索；现按服务端角色过滤。
3. 同时保存可能覆盖新内容；增加串行事务、版本冲突处理，冲突时保留本地草稿。
4. 中文 TXT 被强制按 UTF-8 读取；现识别 UTF-16 标记，并支持无标记 UTF-8、GB18030 文本。
5. 只含学校名称和简介的表格无法识别，空表头也可能误命中别名；补齐识别和回归断言。
6. 批量创建 ID 可能在同一毫秒碰撞；改为随机 UUID。
7. 专业目录一次挂载数百个条目；改为每页 30 条并保持右侧院校同步。
8. 部分强调文字对比度不足；调整颜色并通过自动检查。
